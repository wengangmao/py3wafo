# Native file audit

Every non-MATLAB file is listed in `non_matlab_files.csv` and `.json`, with size, SHA-256, functionality, category and direct MATLAB callers. No binaries were run.

## Interpretation

Python capability replacements are now associated with every native source/binary below. `ported` identifies direct numerical kernels; `algorithm-replacement` consolidates old integration engines into modern implementations; `capability-replacement-limited` identifies explicitly restricted Gaussian wave drivers; `reconstructed` identifies the source-missing down2cc algorithm. These statuses do not certify binary equivalence or full legacy option coverage. See `NATIVE_PYTHON_PORTS.md` and each Python docstring. The earlier pure MATLAB fallbacks remain in `matlab_fallbacks`. Data, documents and images remain assets.

Callers below are conservative static name matches in active MATLAB lines. They exclude full-line comments, but do not resolve every dynamic executable name or Fortran link dependency. See `source/compilation.txt` for driver/link recipes. An empty entry means no direct name match, not that the file is unused. RIND, Jacobian and integration support are transitively needed by the spectrum-to-wave distribution drivers.
